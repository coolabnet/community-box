# Translated research docs

Files under `research/i18n/<lang>/` are generated by `app/scripts/translate-docs.mjs`. Do not edit them by hand unless a wording fix is needed.

- `<lang>/<path>.md`: translation of `research/<path>.md`, with a `sourceHash` in the frontmatter.
- `<lang>/_titles.json`: generated on every run from the translated frontmatter. Do not edit.
- `manifest.json`: lists the served docs. Add new docs here.

Rerunning without `--force` skips files whose `sourceHash` still matches, so hand fixes stay. `--force` overwrites them. Keep the `sourceHash` line when fixing by hand.

Usage and env vars: see `app/README.md` (Translated research docs).
