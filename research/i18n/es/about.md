# Acerca de Community Box

Community Box es un proyecto de investigación y un conjunto de herramientas prácticas diseñado para ayudar a las comunidades a establecer su propia infraestructura digital. Proporcionamos guías completas, recomendaciones de hardware y configuraciones de software para empoderar a las comunidades locales a construir y mantener sus propias redes comunitarias.

## Nuestra Misión

Este proyecto tiene como objetivo reducir las barreras técnicas para las comunidades que buscan establecer su propia infraestructura digital. Nuestro enfoque combina:

- **Investigación**: Análisis de implementaciones previas en el mundo real de infraestructuras comunitarias locales
- **Documentación**: Investigación actual sobre plataformas de hardware y software
- **Pruebas**: Pruebas exhaustivas tanto en dispositivos físicos como en servidores en la nube
- **Guías**: Guías prácticas paso a paso para el despliegue y el mantenimiento

## Orígenes del Proyecto

Este proyecto fue patrocinado por **el proyecto Locnet de APC** y desarrollado por **Luandro**.

La Asociación para el Progreso de las Comunicaciones (APC) es una red internacional de organizaciones que fue fundada en 1990 para proporcionar servicios de comunicación para la paz, los derechos humanos, el desarrollo y la protección del medio ambiente. El proyecto Locnet se enfoca específicamente en apoyar las redes comunitarias locales mediante la investigación, la documentación y la creación de capacidades.

## Lo Que Encontrarás Aquí

- **Cuestionario de Hardware**: Una herramienta interactiva para ayudarte a elegir el hardware adecuado para las necesidades de tu comunidad
- **Guías de Inicio Rápido**: Guías paso a paso para diversas plataformas de hardware y configuraciones de software
- **Documentos de Investigación**: Análisis detallados de implementaciones de redes comunitarias
- **Directorio de Servicios**: Un directorio global de redes comunitarias
- **Calculadora Solar**: Herramientas para planificar despliegues sostenibles fuera de la red eléctrica

## Participa

Las redes comunitarias prosperan gracias a la colaboración. Ya seas un experto en tecnología, un organizador comunitario o simplemente tengas curiosidad por la infraestructura digital descentralizada, hay un lugar para ti en este proyecto.
